## Why this file existed

The failure mode it guards against is the ordinary one: the code lands, the change is obviously right to
whoever made it, and the ADR that now says something false is left standing because updating it is nobody's
task. Six months later the ADR set no longer describes the repo, and the one thing this project claims —
that the design is decided and recorded, not aspirational — stops being true.

This file drifted into exactly that failure itself: rows 6, 7 and 8 sat unticked for a day after their
records were written, which is the same defect one level up. Re-read it against the code before trusting
a checkbox.
